安装rust：

```
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

更新rust：

```
rustup update
```

查看版本号：

```
rustc --version
```

安装rustfmt：

```
rustup component add rustfmt
```

安装rustling：

```
cargo install rustlings
```

编译运行单个rust 文件：

```
rustc xxx.rs
./xxx
```

查看cargo版本（类似cmake，添加依赖项）：

```
cargo --version
```

cargo 生成项目：Cargo 将代码放在 *src* 目录，同时项目根目录包含一个 *Cargo.toml* 配置文件。

```
cargo new hello_cargo --vcs=git #强制生成 Git 文件
```

cargo编译项目：对比cmake

```
mkdir build && cd build   | cargo build
cmake..	 #生成Makefile     |  
make     #读取makefile     |
./xxx					  | cargo run

cargo check #不生成二进制文件并检查语法错误
```

| 命令                         | 用途                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| `cargo run -- run structs1`  | 只检查 `structs1`，可换成其他题目名                          |
| `cargo run -- hint structs1` | 查看该题提示                                                 |
| `cargo run -- run next`      | 运行下一道未完成的题目                                       |
| `cargo run -- hint next`     | 查看下一道未完成题目的提示                                   |
| `cargo run -- list`          | 查看题目列表及 `Done` / `Pending` 标记状态                   |
| `cargo run -- verify`        | 从头检查，遇到首个未通过或仍保留未完成标记的题目时停止       |
| `cargo run -- list`          | 列出所有练习名和当前状态                                     |
| `cargo run -- lsp`           | 生成 `rust-project.json`，供编辑器中的 rust-analyzer 识别各个练习 |
