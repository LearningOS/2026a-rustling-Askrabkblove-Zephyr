安装rust：

```
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

更新rust：

```
rustup update
```

查看版本号：

```
rustc --version
```

安装rustfmt：

```
rustup component add rustfmt
```

安装rustling：

```
cargo install rustlings
```

编译运行单个rust 文件：

```
rustc xxx.rs
./xxx
```

查看cargo版本（类似cmake，添加依赖项）：

```
cargo --version
```

cargo 生成项目：Cargo 将代码放在 *src* 目录，同时项目根目录包含一个 *Cargo.toml* 配置文件。

```
cargo new hello_cargo --vcs=git #强制生成 Git 文件
```

cargo编译项目：对比cmake

```
mkdir build && cd build   | cargo build
cmake..	 #生成Makefile     |  
make     #读取makefile     |
./xxx					  | cargo run

cargo check #不生成二进制文件并检查语法错误
```

| 命令                         | 用途                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| `cargo run -- run structs1`  | 只检查 `structs1`，可换成其他题目名                          |
| `cargo run -- hint structs1` | 查看该题提示                                                 |
| `cargo run -- run next`      | 运行下一道未完成的题目                                       |
| `cargo run -- hint next`     | 查看下一道未完成题目的提示                                   |
| `cargo run -- list`          | 查看题目列表及 `Done` / `Pending` 标记状态                   |
| `cargo run -- verify`        | 从头检查，遇到首个未通过或仍保留未完成标记的题目时停止       |
| `cargo run -- list`          | 列出所有练习名和当前状态                                     |
| `cargo run -- lsp`           | 生成 `rust-project.json`，供编辑器中的 rust-analyzer 识别各个练习 |

我们可以设置 `RUST_BACKTRACE` 环境变量来得到一个 backtrace。*backtrace* 是一个执行到目前位置所有被调用的函数的列表。

```rust
$ RUST_BACKTRACE=1 cargo run
```

当运行多个测试时， Rust 默认使用线程来并行运行。这意味着测试会更快地运行完毕，所以你可以更快的得到代码能否工作的反馈。因为测试是在同时运行的，你应该确保测试不能相互依赖，或依赖任何共享的状态，包括依赖共享的环境，比如当前工作目录或者环境变量。

这里将测试线程设置为 `1`，告诉程序不要使用任何并行机制。

```
$ cargo test -- --test-threads=1
```

如果你希望也能看到通过的测试中打印的值，可以通过在末尾增加 `--show-output` 参数来告知 Rust 显示通过测试的输出：

```
$ cargo test -- --show-output
```

对于想要排除的测试，我们在 `#[test]` 之后增加了 `#[ignore]` 行。现在如果运行测试，就会发现 `it_works` 运行了，而 `expensive_test` 没有运行：

```

#![allow(unused)]
fn main() {
#[test]
fn it_works() {
    assert_eq!(2 + 2, 4);
}

#[test]
#[ignore]
fn expensive_test() {
    // 需要运行一个小时的代码
}
}

```

`expensive_test` 被列为 `ignored`，如果我们只希望运行被忽略的测试，可以使用 `cargo test -- --ignored`：



`cargo run needle haystack` 是运行 Rust 程序并传入两个命令行参数：

- 第 1 个参数：`needle`
- 第 2 个参数：`haystack`

`cargo run` 会先编译再运行当前 crate 的二进制程序，`needle haystack` 会作为程序的命令行参数传入。

```
cargo run needle haystack
```
